أسئلة وأجوبة مقررات Additive Manufacturing 1 (MEC342)

شيت 1 - الأسئلة والأجوبة (جامعة المنصورة الجديدة)

Multiple-Choice Questions

1. Additive Manufacturing (AM) generally creates an object by:
  • A) Removing material from a solid block
  • B) Joining material, usually layer upon layer
  • C) Casting liquid metal in a permanent mold
  • D) Forging material between dies
الإجابة: B) Joining material, usually layer upon layer
2. Which term is also commonly used for Additive Manufacturing?
  • A) 3D printing
  • B) Broaching
  • C) Planing
  • D) Honing
الإجابة: A) 3D printing
3. AM parts are commonly fabricated directly from:
  • A) 2D hand sketches only
  • B) 3D CAD data
  • C) A physical master only
  • D) A CNC tool catalogue
الإجابة: B) 3D CAD data
4. Rapid prototyping describes creating a representation of a system or part:
  • A) Only after mass production
  • B) Before final release or commercialization
  • C) Only by casting
  • D) Only for final products
الإجابة: B) Before final release or commercialization
5. Which process is generally subtractive?
  • A) SLA
  • B) FDM
  • C) CNC machining
  • D) SLS
الإجابة: C) CNC machining
6. A typical AM advantage is:
  • A) Mandatory expensive tooling
  • B) Increasing waste with complexity
  • C) Ability to produce complex geometry without complexity-related tooling cost
  • D) No need for any post-processing in every case
الإجابة: C) Ability to produce complex geometry without complexity-related tooling cost
7. Which is listed as an AM limitation in the lecture?
  • A) Unlimited build size
  • B) All materials can be processed
  • C) Part size and production-series limitations
  • D) No possibility of porosity
الإجابة: C) Part size and production-series limitations
8. AM parts may show anisotropy particularly in the:
  • A) X direction only in every process
  • B) Z or build direction
  • C) Direction of gravity only
  • D) Tool spindle direction
الإجابة: B) Z or build direction
9. Compared with wrought parts, AM parts are described in the lecture as generally having mechanical properties that are:
  • A) Always superior
  • B) Generally inferior, although often superior to cast parts
  • C) Always identical
  • D) Impossible to measure
الإجابة: B) Generally inferior, although often superior to cast parts
10. Which is the correct generic AM process-chain order at the beginning?
  • A) Build → CAD → STL conversion
  • B) CAD → STL conversion → file transfer
  • C) Post-process → machine setup → CAD
  • D) Application → build → STL conversion
الإجابة: B) CAD → STL conversion → file transfer
11. How many main steps are listed in the generic AM process chain?
  • A) 4
  • B) 5
  • C) 8
  • D) 12
الإجابة: C) 8
12. The first step of the AM process chain is:
  • A) Part removal
  • B) Machine setup
  • C) Conceptualization and CAD
  • D) Post-processing
الإجابة: C) Conceptualization and CAD
13. STL was derived from the term:
  • A) Standard Tool Language
  • B) StereoLithography
  • C) Solid Transfer Layer
  • D) Surface Texture Logic
الإجابة: B) StereoLithography
14. An STL file describes a CAD model primarily in terms of its:
  • A) Manufacturing cost
  • B) Geometry using triangular facets
  • C) Chemical composition
  • D) Mechanical test results
الإجابة: B) Geometry using triangular facets
15. STL conversion removes information such as:
  • A) All surface geometry
  • B) Construction data and modeling history
  • C) The part's outer shape
  • D) All triangles
الإجابة: B) Construction data and modeling history
16. In an STL file, triangle surface normals help identify:
  • A) The correct inside and outside of the surface
  • B) The material cost
  • C) The build time only
  • D) The color of the part
الإجابة: A) The correct inside and outside of the surface
17. After STL creation, a common pre-build task is to:
  • A) Verify and orient the part
  • B) Perform tensile testing
  • C) Paint the final part
  • D) Machine all surfaces
الإجابة: A) Verify and orient the part
18. Why might a user reposition a part in an AM machine?
  • A) To change the material's chemical identity
  • B) To locate or orient it appropriately for building
  • C) To eliminate the CAD model
  • D) To avoid converting to STL
الإجابة: B) To locate or orient it appropriately for building
19. Machine setup parameters are:
  • A) Always identical for all AM machines
  • B) Specific to the machine or process
  • C) Never saved
  • D) Unrelated to build quality
الإجابة: B) Specific to the machine or process
20. During the build stage, AM machines commonly repeat:
  • A) Layer control, material deposition, and cross-section formation
  • B) Casting, forging, and rolling
  • C) Drilling, milling, and turning
  • D) Polishing and painting only
الإجابة: A) Layer control, material deposition, and cross-section formation
21. Part removal and cleanup may involve:
  • A) Separating the part from the build platform or excess material
  • B) Creating the original CAD model
  • C) Selecting decision weights
  • D) Converting the file to STL
الإجابة: A) Separating the part from the build platform or excess material
22. Post-processing usually refers to:
  • A) Finishing a part for its intended application
  • B) The first CAD design step
  • C) Only slicing the STL file
  • D) Only transferring the file
الإجابة: A) Finishing a part for its intended application
23. Which is an example of post-processing?
  • A) Surface polishing
  • B) Creating a CAD model
  • C) Generating an STL file
  • D) Selecting build orientation only
الإجابة: A) Surface polishing
24. Why should AM parts be checked before application?
  • A) They may contain voids or have material-bonding issues
  • B) They always have perfect properties
  • C) They never need support removal
  • D) They cannot fail under stress
الإجابة: A) They may contain voids or have material-bonding issues
25. Which group is one of the four broad AM process categories in the lecture?
  • A) Liquid polymer systems
  • B) Forging systems
  • C) Rolling systems
  • D) Machining systems
الإجابة: A) Liquid polymer systems
26. The four broad process categories include liquid polymer, discrete particle, molten material, and:
  • A) Solid sheet systems
  • B) Hot forging systems
  • C) Subtractive systems
  • D) Casting sand systems
الإجابة: A) Solid sheet systems
27. Liquid-based RP systems begin with material in the:
  • A) Solid block state only
  • B) Liquid state
  • C) Gas state
  • D) Finished-part state
الإجابة: B) Liquid state
28. Stereolithography (SLA) uses a photo-curable liquid resin that hardens when exposed to:
  • A) A laser beam
  • B) A cutting tool
  • C) A roller only
  • D) A mechanical press
الإجابة: A) A laser beam
29. The SLA solidification mechanism is called:
  • A) Photopolymerization
  • B) Forging
  • C) Electroplating
  • D) Sinter casting
الإجابة: A) Photopolymerization
30. In SLA, the model is built:
  • A) All at once in one operation
  • B) Layer by layer
  • C) Only by removing material
  • D) By bonding paper sheets
الإجابة: B) Layer by layer
31. In the SLA process, the elevator table typically moves down so that:
  • A) A new layer of resin can cover the previous layer
  • B) The laser can be removed
  • C) The part can be machined
  • D) The CAD model is deleted
الإجابة: A) A new layer of resin can cover the previous layer
32. Before building an SLA part, supports may be designed to:
  • A) Stabilize the part during building
  • B) Increase STL file size only
  • C) Replace the resin
  • D) Remove the need for CAD
الإجابة: A) Stabilize the part during building
33. Which is a stated application of SLA?
  • A) Patterns for investment casting
  • B) Large-scale forging dies only
  • C) Road construction
  • D) Ore extraction
الإجابة: A) Patterns for investment casting
34. Solid Ground Curing (SGC) uses liquid photopolymer resin that solidifies under:
  • A) UV light
  • B) Water pressure
  • C) A cutting blade
  • D) Room lighting only
الإجابة: A) UV light
35. One SGC advantage described is that:
  • A) Wax can provide continuous support, reducing the need for external supports
  • B) It never uses resin
  • C) It does not build in layers
  • D) It requires no data preparation
الإجابة: A) Wax can provide continuous support, reducing the need for external supports
36. Which are the three main SGC process stages listed in the lecture?
  • A) Data preparation, mask generation, model making
  • B) Casting, forging, rolling
  • C) CAD, machining, welding
  • D) Powdering, turning, polishing
الإجابة: A) Data preparation, mask generation, model making
37. In SGC, melted wax is spread into cavities mainly to:
  • A) Provide support and fill the removed-resin regions
  • B) Act as the laser source
  • C) Create the STL file
  • D) Measure hardness
الإجابة: A) Provide support and fill the removed-resin regions
38. The SOUP system is based on:
  • A) Laser lithography technology
  • B) Conventional milling
  • C) Sand casting
  • D) Hot rolling
الإجابة: A) Laser lithography technology
39. Which factor is listed as influencing SOUP performance?
  • A) Laser spot diameter
  • B) Wheelbase of the machine
  • C) Casting flask size
  • D) Drill-point angle
الإجابة: A) Laser spot diameter

Short-Answer Questions

1. Define Additive Manufacturing in your own words using the lecture's description.
الإجابة: صناعة المنتجات بإضافة المواد طبقة فوق أخرى بناءً على بيانات نموذج ثلاثي الأبعاد (3D CAD).
2. Define a prototype and state the purpose of a prototype.
الإجابة: نموذج أولي يتم إنشاؤه لتقييم وتجربة التصميم والتحقق من الشكل والوظيفة قبل الإنتاج التجاري الواسع.
3. List the three aspects used to describe types of prototypes.
الإجابة: الشكل، الوظيفة، والمادة (Form, Fit, and Function).
4. Write the eight steps of the generic AM process chain in the correct order.
الإجابة: 1. CAD, 2. STL, 3. File Transfer & Manipulation, 4. Machine Setup, 5. Build, 6. Removal & Cleanup, 7. Post-processing, 8. Application.
5. Explain why a CAD model is converted to STL before many AM builds.
الإجابة: لأن صيغة STL تُبسط الأسطح المعقدة إلى مثلثات مسطحة تفهمها برامج التقسيم (Slicing) وتتعامل معها ماكينات التصنيع الإضافي.
6. State two problems that may occur in an STL file and explain why they matter.
الإجابة: الفجوات (Gaps) واتجاهات الأسطح غير الصحيحة (Normal orientation)، وتؤدي لفشل طباعة الجزء وتشويه هندسته.
7. Describe the purpose of part orientation and positioning before a build.
الإجابة: لتحسين جودة السطح، تقليل الداعمات (Supports)، وتعبئة مساحة غرفة الطباعة بالشكل الأمثل.
8. Explain the difference between part removal/cleanup and post-processing.
الإجابة: الإزالة والتنظيف تعني فصل الجزء عن المنصة وإزالة الداعمات الأولية، بينما المعالجة اللاحقة (Post-processing) تشمل الصنفرة، الطلاء، والمعالجة الحرارية لتحسين الخصائص والشكل النهائي.
9. List the four broad categories of AM processes presented in the lecture.
الإجابة: 1. السوائل البوليمرية (Liquid polymer)، 2. الجسيمات الدقيقة (Discrete particle)، 3. المواد المنصهرة (Molten material)، 4. الألواح الصلبة (Solid sheet).
10. Explain the principle of SLA and describe how one layer is formed.
الإجابة: تعتمد على تسليط شعاع ليرزر فوق سطح راتنج سائل حساس للضوء (Photopolymer) ليقوم بتصليد مسار طبقة معينة، ثم ينخفض سطح المنصة لطبقة جديدة.

شيت 2 - الأسئلة والأجوبة

Multiple-Choice Questions

1. Discrete particles used in AM are commonly:
  • A) Powders with controlled size and shape
  • B) Only large solid bars
  • C) Liquid resin only
  • D) Paper sheets only
الإجابة: A) Powders with controlled size and shape
2. In powder-based processes, the laser provides energy to:
  • A) Heat and bond powder particles in selected regions
  • B) Cut every part from a sheet
  • C) Wash support material away
  • D) Polish the surface
الإجابة: A) Heat and bond powder particles in selected regions
3. Selective Laser Sintering (SLS) builds parts using:
  • A) Powder and a laser
  • B) Liquid resin and UV exposure only
  • C) Paper and heat-activated adhesive only
  • D) A filament extruded through a nozzle
الإجابة: A) Powder and a laser
4. In SLS, the next powder layer is commonly spread using a:
  • A) Roller
  • B) Hammer
  • C) Drill
  • D) Welding torch
الإجابة: A) Roller
5. In SLS, surrounding unsintered powder can:
  • A) Provide support to the part
  • B) Always become the final part
  • C) Replace the CAD data
  • D) Prevent any layer formation
الإجابة: A) Provide support to the part
6. SLS parts are built by repeatedly:
  • A) Depositing powder, scanning the cross-section, and adding the next layer
  • B) Pouring metal into a mold
  • C) Cutting paper and bonding it only
  • D) Extruding filament through a nozzle
الإجابة: A) Depositing powder, scanning the cross-section, and adding the next layer
7. Molten material systems commonly use a heated material that flows through a:
  • A) Delivery system or nozzle
  • B) Casting flask only
  • C) Grinding wheel
  • D) Vacuum furnace only
الإجابة: A) Delivery system or nozzle
8. Fused Deposition Modeling (FDM) is associated in the lecture with:
  • A) Stratasys
  • B) Cubital only
  • C) Helisys only
  • D) Wohler only
الإجابة: A) Stratasys
9. FDM feedstock is commonly supplied as:
  • A) Filament on spools
  • B) Liquid resin in a vat only
  • C) Loose sand only
  • D) Continuous paper sheets only
الإجابة: A) Filament on spools
10. In FDM, the filament is heated to a:
  • A) Semi-liquid state
  • B) Fully gaseous state
  • C) Cold brittle state
  • D) Chemically inert powder state
الإجابة: A) Semi-liquid state
11. FDM forms the model by depositing material:
  • A) In thin layers along generated tool paths
  • B) By removing chips from a block
  • C) By casting the full shape in one pour
  • D) By bonding only paper sheets
الإجابة: A) In thin layers along generated tool paths
12. In a dual-tip FDM setup, secondary or release material is used to make:
  • A) Support structures
  • B) The CAD model
  • C) The laser beam
  • D) The machine frame
الإجابة: A) Support structures
13. The FDM release material may be removed after building by:
  • A) Washing it away
  • B) Turning the part on a lathe only
  • C) Melting the whole model
  • D) Converting it back to STL
الإجابة: A) Washing it away
14. Laminated Object Manufacturing (LOM) is classified as a:
  • A) Solid sheet system
  • B) Liquid polymer system
  • C) Discrete particle system
  • D) Subtractive-only system
الإجابة: A) Solid sheet system
15. LOM builds parts by:
  • A) Laminating sheet layers and cutting each layer's contour
  • B) Sintering loose powder with a laser
  • C) Curing resin with a laser
  • D) Extruding filament through a nozzle
الإجابة: A) Laminating sheet layers and cutting each layer's contour
16. In LOM, excess material may be cross-hatched so it can:
  • A) Be removed and can support the part during building
  • B) Become the laser source
  • C) Create the CAD file

17. Which is a post-processing category in the lecture?

  • A) Stair-stepping

19. For a matte surface finish, the lecture suggests:
